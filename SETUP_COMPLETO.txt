📋 ¿QUÉ HACE EL SCRIPT?

1. Verifica que Python esté instalado
2. Pregunta si instalar dependencias (tensorflow, numpy, etc.)
3. Intenta descargar modelo pre-entrenado desde GitHub
4. Si falla la descarga → Crea modelo demo con MobileNetV2
5. Guarda modelo en assets/models/food_classifier.tflite
6. Crea archivo food_labels.txt con las 10 comidas
7. Prueba que el modelo funcione correctamente
8. Muestra instrucciones para usar en Flutter

🔧 SOLUCIÓN DE PROBLEMAS COMUNES:

Problema: "Python no está instalado"
Solución: 
• Windows: Descarga desde python.org (marcar "Add to PATH")
• Linux: sudo apt install python3 python3-pip
• Mac: brew install python3

Problema: "No module named tensorflow"
Solución:
• pip install tensorflow==2.15.0
• O usar: pip install -r scripts/requirements.txt

Problema: "Error al descargar modelo"
Solución:
• El script cambiará automáticamente a modo creación
• O forzar modo creación: python download_food_model.py --method create

Problema: "El modelo es muy grande"
Solución:
• Es normal (~12 MB para MobileNetV2)
• Para reducir: usar cuantización INT8
• Alternativa ligera: STM32 Model Zoo (~1 MB)

Problema: "Precisión baja"
Solución:
• El modelo demo tiene limitaciones
• Para mejor precisión, entrena con más datos
• O descarga modelo pre-entrenado completo
